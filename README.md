# TD Git - Calculatrice Simple

Projet d'apprentissage de Git avec une calculatrice en C.

## Compilation

```bash
gcc src/calculator.c -o calculator
./calculator
```

## Description

Ce projet contient une calculatrice simple en langage C utilisée comme support pour l'initiation à Git.

## Contenu du TD

Consultez le fichier `./docs/DiapoHandsOnGithub.pdf` pour suivre les instructions détaillées.
